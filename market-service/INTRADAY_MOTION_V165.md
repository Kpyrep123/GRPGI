# Внутридневное движение акций

Биржа использует `stock-motion-v165.js`. Та же модель включена в запасные генераторы `sync-server` и PocketBase. Клиенты получают готовые серверные котировки; их API и сборка не меняются.

## Поведение

- Цель — заметные движения внутри часа без постоянного роста при пассивном удержании. Это возможности для торговли, а не гарантия прибыли: цена может двигаться против позиции.
- Краткие режимы меняются каждые 5 минут. 12 наборов режимов, случайная ориентация, уровни, сглаженные переходы, шум и редкие импульсы создают рост, откат, боковик и пробои. Нет обязательного сброса цены в начале/конце часа.
- Цена тяготеет к сохранённому `anchor` в логарифмическом пространстве. Половина отклонения без нового движения цели исчезает за 3 минуты. Симметричные направления убирают встроенный положительный тренд; отклонения не накапливаются как обычное случайное блуждание.
- `stockVolatility` продолжает масштабировать амплитуду и шум. Существующие значения не перезаписываются. У модели нет жёсткого верхнего предела цены; остаётся технический минимум `0.01`.
- Изолированная служба сохраняет точные ДМ-импульсы и новую опорную цену после их завершения. Точная ручная установка цены также меняет опору. Такие события могут намеренно изменить долгосрочную стоимость.
- Текущие котировки, заявки, портфели и свечи не сбрасываются. Если у старого JSON-состояния нет опоры, она однократно берётся из текущей цены; последующее редактирование стартовой цены акции не переносит опору автоматически.

## Калибровка

Воспроизводимая симуляция: 24 акции/семени × 24 часа, цена 100, шаг 10 секунд; 576 часовых окон для каждого значения волатильности. Диапазон — `(максимум / минимум − 1) × 100%`, а не доходность торговой стратегии.

| Волатильность | Медианный диапазон за час раньше | Теперь | Медианное изменение после удержания 24 ч | Медианное абсолютное изменение за 24 ч |
|---|---:|---:|---:|---:|
| 0.5 | 0.2074% | 5.8233% | +0.0225% | 1.3342% |
| 1 | 0.4149% | 11.9854% | +0.0452% | 2.6507% |
| 2 | 0.8317% | 25.4074% | +0.0904% | 5.2306% |

Для стандартной волатильности 10-й–90-й процентили часового диапазона: **9.5114–15.0769%**. Среднее, а не медианное, подписанное изменение после удержания 24 ч: **+0.2913%**. Эти числа относятся к указанной тестовой выборке; они не задают пределы цены или гарантированный доход отдельного игрока. Секундный и десятисекундный генераторы имеют сопоставимую амплитуду, но разные последовательности дискретного шума; в работающей кампании все клиенты читают один сервер.

## Проверки

```bash
node tests/stock-motion-v165.mjs
node tests/stock-motion-v165.integration.mjs
node tests/v148-stock-exchange.mjs
node tests/v148-pocketbase-stock.mjs
node tests/v151-market-calibration.mjs
node tests/v152-market-patterns-colors.mjs
```

Первый тест сравнивает прежнюю модель с новой, проверяет движения в обе стороны, длительное удержание, возврат к опоре, воспроизводимость, шаг времени и миграцию/перезапуск. Второй запускает настоящую Node/SQLite-службу на временных БД: обычный внутридневной TP без ДМ-события, лонг/шорт, лимиты, SL, ручные импульсы, свечи и сохранность состояния.

## Применение после слияния

Для установленной изолированной службы из корня репозитория обновляются **оба** файла:

```bash
sudo install -m 644 market-service/server.js market-service/stock-motion-v165.js /opt/grpgi-market-service/
node --check /opt/grpgi-market-service/server.js
sudo systemctl restart grpgi-market
```

Существующие SQLite-БД остаются на месте. Публикация сайта и новый установщик не нужны. Если маршруты обслуживает PocketBase, обновляются `grpgi_stock_exchange_v148.js` и `stock-motion-v165.js` в его `pb_hooks`, затем перезапускается PocketBase. Для `sync-server` обновляются `stock-exchange-v148.js` и соседний `stock-motion-v165.js`, затем перезапускается этот процесс. Следует обновлять тот сервер, который фактически обслуживает маршрут биржи; репозиторий сам по себе не меняет работающую службу.
