# Переход GRPGI на анонимные запросы PocketBase

Клиент в ветке `feat/anonymous-pocketbase-access` больше не получает токен общего аккаунта `app_users`. Пароль персонажа при входе в профиль не меняется. До настройки рабочего сервера **не публикуйте этот клиент**: текущие правила и часть маршрутов `pb_hooks` требуют авторизации и ответят 401/403.

## Изменения на сервере

1. Сохраните резервную копию `pb_data` и отдельных файлов `/opt/pocketbase/pb_hooks`. Не заменяйте каталог hooks целиком.
2. Проверьте фактические имена коллекций в PocketBase: `campaign_snapshots`, `campaign_players`, `campaign_messages`, `campaign_combat_runtime`, `campaign_assets`. Для операций, которые должен выполнять клиент, измените правила List, View, Create и Update с `@request.auth.id != ""` на пустую строку (`""`). Delete оставьте закрытым, если клиент не удаляет записи напрямую. Для иных правил проверьте поля и фильтры отдельно; не заменяйте их вслепую.
3. Проверьте **текущие** файлы `/opt/pocketbase/pb_hooks` для маршрутов `/api/grpgi/market/*`, `/api/grpgi/character-applications/*`, передачи добычи, денег и проверки целостности. В поставке GitHub этих файлов нет. Уберите обязательную проверку токена там, где маршрут вызывается игроком, сохранив проверку тела запроса, разрешённых операций и атомарность покупок. Простое открытие правил коллекций эти маршруты не исправит.
4. Проверьте анонимные List, View, Create, Update, загрузку файлов и подписки `/api/realtime`. Проверьте покупку, акции, инвентарь, навыки и заявку персонажа через обновлённые клиенты на тестовых данных. После проверки опубликуйте веб и ПК версии.

## Что меняется в коде

- Electron и веб отправляют запросы без `Authorization` и без `/auth-with-password`.
- DEV-публикация веба записывает в `runtime-config.js` только адрес сервера, кампанию и имена коллекций.
- Старый токен общего аккаунта удаляется из хранилища веб-клиента при запуске; прежние учётные данные в локальном файле конфигурации Electron больше не используются.
- Логин персонажа, роль ДМа и проверки клиентского интерфейса остаются отдельной логикой. Анонимный клиент сможет вызвать открытый серверный маршрут вне интерфейса.

На данный момент исходники актуальных серверных hooks отсутствуют в `Kpyrep123/GRPGI`. Без них нельзя подготовить и проверить точные правки серверных маршрутов. Документ фиксирует обязательные действия перед развертыванием клиентов.

Справка PocketBase: https://pocketbase.io/docs/api-rules-and-filters/ — пустое правило разрешает запросы без авторизации.
