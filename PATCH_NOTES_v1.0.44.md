# GRPGI 1.0.44 — Web Galaxy Map

## Web desktop
- Широкая браузерная версия (`min-width: 901px`) теперь использует интерактивную галактическую карту как основной экран «Навигатор».
- Поддерживаются drag/pan, wheel zoom, hover-подсказки, выбор системы, вход в систему, орбиты и выбор планет.
- Показываются видимые для текущего игрока системы, маршруты, текущая система персонажа и карточка выбранной системы/планеты.
- Для фона используются существующие `galaxy1.png` и `galaxy2.png`.

## Mobile web
- При ширине до 900 px сохраняется прежний облегчённый карточный навигатор без canvas-карты.
- Native Android-клиент не изменён.

## Login flow
- Экран «Подключение к кампании» больше не является стартовым.
- Стартовый экран — выбор персонажа и пароль персонажа.
- URL PocketBase и основная кампания берутся из встроенных безопасных defaults/сохранённой конфигурации.
- Сохранённый PocketBase token продолжает использоваться автоматически.
- Для нового устройства без действующего PocketBase token оставлена отдельная кнопка «Технические настройки». Она нужна только для одноразовой технической авторизации и не смешана с обычным игровым входом.
- Пароль `app_users` не встроен в публичный JavaScript.
