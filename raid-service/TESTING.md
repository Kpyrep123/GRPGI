# Первый тест основных механик вылазки

Объём этого этапа: текущие правила боевых сцен для атак по возможности, Отхода, Помощи и устройств; ящики, цели, переходы и эвакуация. Проверка отдельных навыков и взаимодействие с дверями/терминалами выполняются следующим этапом.

## Подготовка

Обновить серверные hooks и Node worker по [README.md](README.md#установка-сервера), затем выполнить Deploy Web. Одного обновления сайта недостаточно. Зависимость `wasmoon` должна быть доступна для корневого `lua-sandbox-worker.cjs`: установить зависимости в корне развёрнутого проекта (`npm ci --omit=dev --ignore-scripts`), проверить `node -e "require('wasmoon')"` из этого каталога.

Использовать копию кампании и тестовые профили: попытка сохраняет настоящие расходы, повреждения и смерть. Подготовить двух игроков, два оружия (одно с несколькими выстрелами), боеприпасы, гранату, дрон, турель и соседнего противника с ближним оружием. На первой карте разместить ящик и переход, на второй — цель и эвакуацию. Карты включить в миссию через World Config; после правок сцен пересохранить миссию.

Начать в доступное окно: пятница 20:00 — понедельник 08:00 по Москве. Для проверки в другое время ДМ может выбрать «Открыто вручную» в поле «Время доступа» раздела «Вылазки — тест» и сохранить настройки. После теста вернуть «По расписанию». Для повторного прогона использовать отдельную копию кампании/данных: завершение попытки ДМом не выдаёт вторую попытку за ту же неделю.

## Порядок проверки

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Двумя аккаунтами прийти к НПС, создать группу, подтвердить готовность, начать | Входят только приглашённые готовые участники; позднее присоединение закрыто |
| 2 | Походить, скрыть окно, открыть его снова, обновить страницу | Позиции, очередь и расходы сохраняются; новый ход не выдаётся |
| 3 | Выполнить одиночную атаку, затем начать очередь | Действие расходуется один раз; следующие выстрелы доступны при потраченном Действии; оружие очереди зафиксировано |
| 4 | Досрочно завершить очередь | Дополнительный выстрел не производится; Действие остаётся потраченным; оставшееся перемещение доступно |
| 5 | Перезарядить, использовать гранату, получить урон | Сервер считает броски и расход; сохраняются HP, травмы, боеприпасы и прочность; запроса Инстинкта нет |
| 6 | Выйти из соседства с противником; в другом ходе сначала применить Отход | В первом случае реакция разрешается до шага; во втором движение защищено Отходом |
| 7 | Передать Помощь для Активной брони, выполнить атаку, затем защититься | Атака бонус не расходует; подходящая проверка расходует его один раз; повторная Помощь тем же помощником в этой сцене закрыта |
| 8 | Разместить дрон, отдать простую и сложную команды, переместить/атаковать, вернуть к оператору | Соблюдаются стоимость и ограничения команд; видно оружие устройства; возврат сохраняет экземпляр и состояние |
| 9 | Разместить турель и попробовать переместить; отдалить дрон до потери связи | Турель неподвижна; операции устройства без связи отклоняются |
| 10 | Обыскать поверженного и открыть ящик; забрать часть добычи | Обыск расходует Действие; количества, вместимость, прочность и экземпляры сохраняются после обновления страницы |
| 11 | Поднять союзника, перейти всей группой на следующую карту | Руки заняты, скорость уменьшена; переносимый союзник следует за носителем; переход не восстанавливает ресурсы |
| 12 | Выполнить цель и запустить эвакуацию | Остаток текущего раунда не считается; отсчитываются три следующих полных раунда |
| 13 | Оставить одного участника за зоной, остальных — внутри, включая переносимого | В зоне эвакуируются живые, включая бессознательного/умирающего; снаружи погибают |
| 14 | Получить награду и открыть обычные профили | Деньги делятся поровну выжившим, очки выдаются каждому, предметы выбираются по очереди; добыча и расходы сохранены, блокировка профиля снята |

Развёрнутые устройства перед переходом и эвакуацией нужно вернуть в инвентарь: автоматического возврата нет. Для турели возврат этим режимом не предусмотрен.

Для ошибки записать шаг, карту, раунд, персонажа, выбранное оружие/устройство, текст ошибки и последние строки журнала. Отдельно проверить геометрию сложных препятствий и размеры токенов: полное совпадение с десктопной сценой ещё не подтверждено.

## Автоматические проверки

Из корня проекта выполнить `npm run test:pr`. Набор проверяет правила, сохранение и повторы, настоящий Lua sandbox, SQL-обработчики через SQLite и DOM клиентов. Он не заменяет одновременное прохождение несколькими браузерами на установленном PocketBase.
