Когда вы можете играть?

Отметьте все подходящие варианты. Ответ можно изменить до завершения голосования.

Голосование не является записью. После выбора даты участие подтверждается отдельной кнопкой.

Как выбирается дата

Видно число доступных игроков. Рекомендуемый вариант выделен; окончательную дату утверждает ДМ.

Для продолжения партии сначала опрашивается прежний состав.

    Участие подтверждается отдельно

    До срока подтверждения места прежнего состава сохраняются. Затем неподтверждённые места освобождаются для открытой записи.

    При заполненном лимите записаться нельзя. Повторное нажатие не создаёт второе место.
    Управление макетом
    Уведомления: новое задание → началось голосование → выбрана дата → подтвердите участие → открылась запись. При переносе даты подтверждение запрашивается заново.
