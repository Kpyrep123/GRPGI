# GRPGI 1.0.80 — прокрутка категорий архива

## Исправления

- Убрано ограничение высоты боковой панели архива, из-за которого большое число категорий сжималось в тонкие полосы.
- Каждая категория теперь сохраняет читаемую минимальную высоту независимо от количества категорий.
- Список категорий получил собственную вертикальную прокрутку в приложении и веб-версии.
- Добавлен заметный, но ненавязчивый индикатор прокрутки.
- Длинные названия категорий переносятся внутри строки и не ломают компоновку.

## Установка

1. Наложить архив на корень проекта с заменой файлов.
2. Выполнить обычный `ДЕПЛОЙ WEB`.
3. Собрать установщик GRPGI 1.0.80.
4. Заменить файл `GRPGI-Setup-latest.exe` на сайте.

Изменения PocketBase, перезапуск PocketBase и reload Caddy не требуются.
