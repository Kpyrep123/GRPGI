# Мобильный и веб-клиент: PocketBase

Мобильная и браузерная версии подключаются только к PocketBase. Экран настройки принимает URL сервера, учётную запись коллекции `app_users`, идентификатор кампании и имена рабочих коллекций.

## Обязательные параметры

- `SERVER_URL`
- `APP_USER_EMAIL`
- `APP_USER_PASSWORD`
- `CAMPAIGN_ID`
- `DEVICE_LABEL`

Расширенные параметры позволяют изменить коллекции снапшотов, игроков, чата, боевого runtime, пользователей и ассетов.

## Безопасность

Клиент проходит `auth-with-password` в PocketBase и отправляет полученный токен в `Authorization`. Правила коллекций должны ограничивать чтение и запись данными нужной кампании и ролью пользователя. Не храните административный токен PocketBase в клиентском коде.

## Realtime

Клиент подписывается на PocketBase realtime API для коллекций кампании. Периодический polling остаётся страховкой на случай разрыва SSE-соединения.

## Сборка мобильной версии

```bash
cd webapp_work/mobile
npm install
npm run sync
npm run open:android
```

Перед выпуском проверьте вход, загрузку снапшота, обновление профиля игрока, чат, realtime и отображение ассетов PocketBase.
