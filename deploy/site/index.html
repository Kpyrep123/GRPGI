Galactic RPG Interface

Клиент кампании

Доступны два варианта: полная ПК-версия Electron-приложения для ДМа и браузерная web-версия, которая автоматически адаптируется под настольные компьютеры и телефоны.

Сервер синхронизации: https://sync.grpg-sync.ru
Windows / ПК

Полное приложение

Полная Electron-версия: режим ДМа, World Config, глобальная карта, второй экран, редакторы, боевые сцены, архив, чат, профиль и PocketBase-синхронизация.

Скачать ПК-версию

После сборки переименуй установщик в GRPGI-Setup-latest.exe и положи в downloads.

Web / ПК и телефон

Открыть в браузере

Web-клиент для игроков и ДМа с полноценной интерактивной галактической картой на широких экранах. На телефонах этот же сайт автоматически переключается на облегчённую адаптацию без отдельного приложения. Игровой мир в браузере не кешируется постоянно; по явному выбору можно запомнить защищённую сессию и выбранный профиль на срок до 30 дней.

Открыть web-версию

При входе профилем ДМа доступны все статьи и игровой контент независимо от ограничений видимости. Редактирование World Config и тяжёлые мастерские инструменты остаются в ПК-приложении.

Конфиденциальность

Для открытия сайта и загрузки приложений отдельное согласие не требуется. Web-клиент сохраняет вход только после включения опции «Запомнить вход на этом устройстве».

Политика конфиденциальности описывает серверную обработку, техническое локальное хранение и способы удалить сохранённый вход.
