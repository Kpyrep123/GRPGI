Galactic RPG Interface

Клиент кампании

Здесь размещаются три варианта доступа: полная ПК-версия Electron-приложения, браузерная web-версия с внешним видом ПК-клиента и Android-версия для телефонов.

Сервер синхронизации: https://sync.grpg-sync.ru
Windows / ПК

Полное приложение

Полная Electron-версия: режим ДМа, World Config, глобальная карта, второй экран, редакторы, боевые сцены, архив, чат, профиль и PocketBase-синхронизация.

Скачать ПК-версию

После сборки переименуй установщик в GRPGI-Setup-latest.exe и положи в downloads.

Web / ПК и телефон

Открыть в браузере

Player-only web-клиент с визуальным стилем ПК-приложения. Данных в постоянный локальный кеш не пишет: подключается к PocketBase, читает облако и отправляет изменения обратно.

Открыть web-версию

Нет режима ДМа, World Config и тяжёлых боевых сцен. Для управления миром используй ПК-приложение.

Android / телефон

Мобильная версия

Игровой клиент без режима ДМа. Вместо галактической карты используется лёгкая навигация по системам и планетам.

Скачать APK

После сборки APK переименуй его в GRPGI-Mobile-latest.apk и положи в downloads.

Согласие и конфиденциальность

Без согласия ссылки на web-клиент и загрузку приложений остаются заблокированными.
