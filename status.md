## Боевые сцены: базовое управление дронами и турелями / v200 (2026-10-28)

Основа: `main` / `b7190c8`, после слитого PR #75. По новой очередности сначала реализуется базовый движок устройств, затем согласовываются Lua-исключения. Это первая часть этапа 9, а не завершение всех правил дронов. Новых Lua-команд, hooks и именных исключений имплантов нет.

### Выполнено

- [x] «РАЗВЕРНУТЬ ДРОН» и «РАЗВЕРНУТЬ ТУРЕЛЬ» доступны при наличии соответствующего предмета в настоящем инвентаре выбранного оператора (игрока или экземпляра NPC). Развёртывание в свободный соседний гекс расходует одно Действие в бою и один предмет; не выполняет атаку. Исправлена прежняя потеря списания при изменении временной нормализованной копии профиля. Нельзя развернуть сломанный предмет, выйти за карту/занять препятствие или обойти предел связанных дронов по Интеллекту.
- [x] Устройство получает ссылку на оператора, его сторону, состояние прочности/зарядов и магазина исходного предмета. Расходы развёртывания включены в существующий журнал операций v194; повтор записи не создаёт второе устройство и не списывает ещё один предмет. Карточки одинакового типа пока используют старую модель состояния предмета по itemId, без новой миграции экземпляров инвентаря.
- [x] Чистая модель `renderer/combat-devices-v200.js`: одна простая бесплатная команда только движения и одна сложная за Действие за интервал собственного хода оператора. Простая и сложная направляются разным устройствам. Восстановление Действия не обнуляет лимит сложной команды. Лимиты привязаны к ID боя и счётчику собственного хода, а не только номеру раунда. Пауза, JSON, перенос карты и позднее размещение не создают новый такт.
- [x] Сложная команда разрешает движение до **или** после одной активной операции. Если до операции уже потрачено движение, после неё оно закрыто; если нет, остаток доступен после операции. Скорострельность штатного оружия составляет одну операцию, с прежними патронами/штрафами/сменой целей; во время очереди движение запрещено. Явное завершение закрывает команду без возврата цены. В конце хода оператора незаконченная очередь устройства закрывается.
- [x] Команда «Рывок» расходует Действие оператора и сложную команду, удваивает движение устройства вместо активной операции. Простая команда и Рывок не разрешают атаку/активный модуль. Повторная команда в том же интервале не обнуляет уже пройденное расстояние.
- [x] Дроны и управляемые турели не включаются в инициативу и не имеют своей доступной Реакции. Турель — неподвижное устройство, управляемое оператором: сложная команда разрешает одну операцию, простая/Рывок недоступны. Автоматическую стрельбу и отдельное правило автономной турели этот пакет не вводит.
- [x] Атака устройства: физический d20 + актуальный Интеллект оператора + явный бонус устройства, с общим штрафом проверок оператора. Убрано угадывание бонуса по названию навыка. Дальность/линия огня/укрытие считаются от устройства; магазин, скорострельность, износ и критические значения используют общий путь. Существующий `StandardAttack` использует ту же формулу для устройств; новых разрешений на команды из Lua не добавлено. Перезарядка по сложной команде берёт совместимые патроны из реального запаса оператора и занимает активную операцию.
- [x] Связь проверяется при выдаче команды и исполнении: базовая дальность 30 гексов, существующая проверка полного перекрытия связи, заглушение, HP/состояние/вывод оператора и устройства. Перед движением и выстрелом повторная проверка после реакций. При потере связи новые атаки/маршрутное движение блокируются; безопасное поведение по умолчанию — остановка, без автоматического возврата или самостоятельной атаки.
- [x] Интерфейс показывает оператора, связь, вид команды и доступность операции. Есть «ВЫБРАТЬ ОПЕРАТОРА» и «ЗАВЕРШИТЬ КОМАНДУ». Окно управления имеет выбор устройства/вида команды, объясняет запрет и блокирует подтверждение недоступного приказа. В подготовке карты оператор заранее поставленного устройства назначается в инспекторе; смена оператора во время начатого/приостановленного боя не используется для обновления ресурсов.

Старое поле сохраняется как данные, но его активный чекбокс убран; установка имплантов и их карточки не мигрируются. Нейроинтерфейс/Shepherd и любые другие исключения будут только через отдельно согласованные общие Lua-возможности.
