# GRPGI 1.0.52 — Character Registration, Origins & Equipment Schema

## Вход и кампании
- Кампании с `availableNow: false` полностью исключены из селектора входа в Electron и Web.
- Эпоха кампании больше не выводится в меню выбора кампании при входе.
- Персонажи недоступных кампаний не появляются в списке входа.
- Анкеты со статусом `pending` или `rejected` также исключены из входа.

## Регистрация персонажей
- Добавлена регистрация персонажа на экране входа Electron и Web.
- Поля анкеты: фото, имя, описание, кампания, социальное происхождение, географическое происхождение, пароль.
- Новая анкета создаётся со статусом `pending` и недоступна для входа до решения ДМа.
- В Electron World Config / отчётах ДМ видит ожидающие заявки и может одобрить или отклонить их.
- В Web-профиле ДМа также добавлена модерация ожидающих заявок.

## Происхождения
- В World Config добавлены два независимых справочника:
  - `Происхождение: социальное`;
  - `Происхождение: географическое`.
- У происхождения есть название, изображение, описание, модификаторы характеристик и стандартная видимость по персонажу / кампании / эпохе.
- Модификаторы обоих происхождений складываются с базовыми характеристиками персонажа.

## Экипировка
- Каталог предметов приведён к четырём категориям: `gear`, `weapon`, `armor`, `implant`.
- В World Config раздел «Снаряжение» получил четыре явных вкладки: Снаряжение / Оружие / Броня / Импланты.
- Снаряжение хранит только общие свойства предмета.
- Оружие: урон, бонус к попаданию, слот, требования характеристик.
- Броня: класс брони, требования характеристик.
- Импланты: требуемая энергия, требования характеристик; установка хранится отдельно у каждого персонажа.
- Встроенный `equipment.json` мигрирован на новую схему; устаревшие типы сведены к `gear`.

## Удалённые механики предметов
- Интерактивные механики дешифратора, быстрого взлома и дверного/обычного взлома выведены из интерфейса и исполнения.
- Поля `mechanicType`, `decryptorMode`, `mechanicTitle`, `mechanicHint` и связанные параметры больше не сохраняются новой схемой.
- Старый «Полевой дешифратор» остаётся обычным предметом без мини-игры.

## Класс брони
- В профиль добавлен показатель КБ.
- У персонажа есть базовый КБ (`baseArmorClass`, по умолчанию 10).
- Надетая броня с заданным `armorClass` заменяет базовое значение КБ.
- КБ отображается и в Electron, и в Web.

## Web DM
- Web-ДМ обходит обычные ограничения видимости и видит статьи, планеты, задачи, новости и другой игровой контент так же, как ДМ в настольном приложении.
- В Web-профиле ДМа доступны ожидающие заявки персонажей с кнопками одобрения и отклонения.

## Совместимость
- Старые персонажи без `approvalStatus` считаются одобренными.
- Старые персонажи без `baseArmorClass` получают базовый КБ 10.
- Старые предметы автоматически приводятся к одной из четырёх новых категорий.
- Патч не требует установки npm-зависимостей и рассчитан поверх версии 1.0.51.
