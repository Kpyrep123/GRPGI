# Galactic RPG Interface 1.0.43

## Исправление критического расхода памяти

Причина падения `JavaScript heap out of memory` устранена архитектурно.

Раньше крупное изображение одновременно существовало в памяти как:

- объект `File`;
- Base64 Data URL;
- IPC-копия строки;
- Node.js `Buffer`;
- `Blob`/`FormData`;
- копия полного world snapshot;
- ответ IPC с повторной копией мира.

Теперь обычные PNG/JPG/GIF/WebP:

1. Передаются из renderer в main process как путь к файлу.
2. Копируются в `world-data/assets` без Base64.
3. Хешируются потоково.
4. Загружаются в PocketBase через потоковый multipart-запрос.
5. Нормализуются в cloud URL только один раз.

Локальное сохранение мира больше не запускает повторную загрузку всех изображений. Полная cloud-нормализация выполняется только во время `sync:push`.

## Миграция старых изображений

Старые `data:image/...;base64,...`, ранее записанные в world/state JSON, автоматически переносятся в `world-data/assets` при загрузке. В JSON остаётся `file://` URL вместо огромной строки.

Это позволяет восстановить проект после предыдущего неудачного сохранения без ручного редактирования JSON.

## Второй экран

На player display перенесено полное визуальное состояние Region Command Center:

- поверхность, воздух и орбита;
- фильтр слоёв;
- сетка и подписи;
- туман войны и области обзора;
- активная РЛС;
- пассивные сенсоры;
- зоны РЭБ;
- радарные контакты без раскрытия скрытых объектов;
- маршруты кораблей и отрядов;
- траектории и полёт ракет;
- взрывы;
- дальность по топливу;
- дальность вооружения;
- состояние корпуса и топлива;
- выбранный ДМом объект и его тактическая сводка;
- масштаб, позиция камеры, пауза и ускорение времени.

Второй экран остаётся player-facing представлением. Управление и редактирование выполняются ДМом в основном окне.

## Снижение фоновой нагрузки

Player display больше не перечитывает весь world snapshot четыре раза в секунду. Обновления приходят по IPC-событиям после сохранения state/world. Резервный полный опрос выполняется раз в 10 секунд.

Туман войны на втором экране рендерится в ограниченном canvas-разрешении, а перемещение объектов и ракет обновляется без полной пересборки DOM.

## Установка

Закрыть приложение и распаковать patch поверх версии 1.0.42:

```powershell
Expand-Archive -Force `
  "C:\путь\GRPGI_MEMORY_SECOND_SCREEN_FIX_1.0.43_PATCH.zip" `
  "C:\app_backup"
```

После этого запустить существующим способом:

```cmd
cd /d "C:\app_backup"
npm start
```

Установка или обновление npm-пакетов для этого patch не требуется.
