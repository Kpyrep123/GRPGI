# Выделенный sync-сервер

Каталог `sync-server` содержит сервер синхронизации, который хранит данные кампаний на диске, принимает ассеты и отправляет realtime-события через SSE.

## Запуск через Docker Compose

```bash
cd sync-server
docker compose up -d --build
```

Задайте постоянный каталог данных, токен доступа и откройте сервер только через HTTPS reverse proxy.

## Настройка клиента

В панели синхронизации выберите `Custom self-host` и укажите:

- `SERVER_URL` — публичный HTTPS-адрес сервера;
- `ACCESS_TOKEN` — токен сервера;
- `CAMPAIGN_ID` — идентификатор кампании;
- `DEVICE_LABEL` — имя устройства.

Данные мира, игроков, чата, боевого runtime и ассеты обрабатываются API из `sync-server/server.js`.
