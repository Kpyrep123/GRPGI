# DEV automation patch

- Панель автоматизации видна только в DEV-режиме и профиле ДМа.
- Добавлена публикация patch-версии исходников напрямую в `origin/main` без сборки Electron/Android.
- Добавлена блокировка неожиданных удалений, секретов и слишком крупных Git-файлов.
- Добавлен прямой SSH/SCP-деплой `deploy/site` с сохранением `/downloads`, HTTP-проверкой и rollback.
- Добавлен чистый ZIP исходников для передачи без `.git`, `node_modules`, аудио, сборок, Android build, секретов и крупных файлов.
- Добавлен manifest ZIP с SHA-256 и перечнем исключений.
