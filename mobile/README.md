# GRPGI Android — 1.0.142

Android использует тот же интерфейс, что и `deploy/site/app/`: профиль, инвентарь, архив, терминал и синхронизацию PocketBase. Каталог `mobile/www` оставлен как исторический исходник и больше не включается в сборку.

## Сборка из корня репозитория

```sh
npm run mobile:install
npm run mobile:sync
npm run mobile:open:android
```

`mobile:sync` автоматически выполняет `tools/prepare-mobile.cjs`, создаёт `mobile/generated-www`, затем синхронизирует Capacitor Android. После изменения веб-клиента перед каждой сборкой повторять `npm run mobile:sync`. Для APK использовать Build в Android Studio; для выпуска подписать сборку существующим ключом приложения.

`generated-www` не хранится в Git. Конфигурация подключения берётся из общего клиента. Локальный веб-файл `runtime-config.js` с параметрами конкретного деплоя не копируется: сборка получает пустой runtime override и стандартные настройки клиента. Ввод логина PocketBase при сборке не требуется.

Профиль адаптируется к ширине экрана. Касание предмета открывает меню с полными характеристиками и действиями «Надеть» / «Снять». Снаряжение меняется через существующую очередь сохранений; перемещение мышью в веб-клиенте сохранено. Импланты — до четырёх квадратных слотов в строке.

Проверка 1.0.142: сгенерированный Android HTML выполнен в Chromium с сенсорным экраном 390 px, включая надевание/снятие. Нативный APK и работа на физическом устройстве в этой среде не проверены.
