# Galactic RPG Mobile

Мобильная часть теперь живёт в той же папке проекта, но работает как **player-only клиент**.

Что уже есть в web-слое `mobile/www/`:
- первое окно настройки Supabase, как на ПК;
- безопасная модель синхронизации: мобильный клиент **не пишет** общий `campaign_snapshots`;
- автоматическая подгрузка кампании из облака и fallback на локальный кеш;
- вход по персонажу и паролю;
- обязательные модули игрока:
  - навигатор по системам и планетам вместо тяжёлой глобальной карты;
  - архив / статьи / планеты / системы / новости / задания;
  - торговый терминал только для текущей планеты персонажа;
  - чат;
  - просмотр боевых сцен и живого журнала;
  - профиль и инвентарь.

## Что мобильная версия меняет в облаке

Только три безопасных типа данных:
- строку текущего игрока в `campaign_players`;
- отправленные сообщения в `campaign_messages`;
- локальный кеш на телефоне.

Она **не трогает**:
- общий world snapshot кампании;
- DM-режим;
- World Config;
- редакторы сущностей;
- локальные файловые операции Electron.

## Первый запуск

Из корня проекта:

```bash
npm run mobile:install
npm run mobile:android:init
npm run mobile:sync
npm run mobile:open:android
```

Подробный пошаговый путь — в `MOBILE_PORT_GUIDE.md`.
