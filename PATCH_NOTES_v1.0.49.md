# GRPGI 1.0.49 — Campaign Eras & Interface Themes

## Кампании
- Добавлены `availableNow` и `era`.
- Недоступная кампания остаётся в конфигураторе, но не может быть выбрана при входе.
- Персонажи недоступной кампании не отображаются в списке входа.
- Поддерживаются эпохи `medieval`, `industrial`, `technological`.
- Старые кампании без новых полей мигрируют как `availableNow: true` и `era: technological`, поэтому обновление не блокирует существующих игроков.

## Темы
- Средневековье: пергамент, дерево, чернила и восковые акценты.
- Индустриальная: воронёный металл, приборные панели и янтарные индикаторы.
- Технологичная: чёрно-сепийный интерфейс с тонкими золотыми линиями в стилистике нового арт-направления.
- Тема переключается по выбранной кампании на ПК и в web-клиенте.
- Region Command Center наследует эпоху кампании.
- Второй экран автоматически получает ту же эпоху, что и активная кампания ДМа.

## Доступность контента
World Config теперь имеет три независимых уровня назначения: персонаж, кампания и эпоха. Совпадение любого из выбранных уровней даёт доступ. Пустой список сохраняет текущую безопасную семантику GM-only.

## Web
- Добавлен выбор доступной кампании перед выбором персонажа.
- Список персонажей фильтруется по кампании.
- Убран Android/APK с публичной страницы; телефон использует адаптивный web-клиент.
- Android-ориентированные fallback-метки записи заменены на `web-player`.
