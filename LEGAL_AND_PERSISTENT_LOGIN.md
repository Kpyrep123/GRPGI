# GRPGI Web: правила использования, конфиденциальность и сохранённый вход

## Что реализовано

- Web-клиент работает только с PocketBase.
- При загрузке удаляются старые browser-storage записи прежнего backend.
- Функция «Запомнить вход на этом устройстве» включается самим пользователем.
- Срок локального хранения ограничен 30 днями.
- Сохраняются только:
  - URL PocketBase;
  - идентификатор кампании и названия коллекций;
  - email/технический логин `app_users`;
  - токен PocketBase и срок его действия;
  - идентификатор выбранного персонажа;
  - локальные отметки прочитанных материалов.
- Пароль `app_users` и пароль персонажа приложением в `localStorage` не записываются.
- Без функции запоминания технические данные живут только в `sessionStorage` до закрытия вкладки.
- «Выйти из профиля» удаляет выбранный профиль, но оставляет действующее PocketBase-подключение.
- «Забыть устройство» удаляет конфигурацию, токен, профиль и локальные UI-метки.
- Перед входом пользователь обязательной отметкой принимает Правила использования и подтверждает ознакомление с Политикой конфиденциальности; оба документа объединены в `deploy/site/privacy.html`.
- Удаление сообщения из интерфейса является мягким: сервер сохраняет исходный текст и метаданные с отметкой `deletedAt`.

## Ограничение безопасности

Токен PocketBase хранится в `localStorage` и доступен JavaScript-коду страницы. Это приемлемый компромисс для текущего статического SPA, но слабее серверной сессии в cookie `HttpOnly; Secure; SameSite`.

Для следующего уровня защиты нужен same-origin backend/BFF, который будет хранить PocketBase-токен на сервере и выдавать браузеру только HttpOnly session-cookie.

## Обязательные действия владельца сайта

Перед публичным использованием заполнить в `deploy/site/privacy.html`:

- полное имя или наименование оператора;
- почтовый адрес оператора;
- актуальный контакт для запросов о данных;
- фактического хостинг-провайдера и категории получателей;
- реальные сроки хранения server access/error logs;
- применимое правовое основание обработки.

Также необходимо установить `pocketbase/pb_hooks/grpgi_chat_retention.pb.js` в рабочий каталог PocketBase `pb_hooks` и перезапустить службу. Хук защищает мягко удалённые сообщения от физического удаления и перезаписи обычным клиентом.

Проверить необходимость:

- Impressum по § 5 DDG;
- договора обработки данных (AVV/DPA) с хостинг-провайдером по статье 28 GDPR;
- немецкой версии политики, если сервис ориентирован не только на русскоязычную закрытую группу;
- отдельного порядка для несовершеннолетних, если они допускаются к сервису.

## Caddy

После обновления `deploy/caddy/Caddyfile.app.example` перенести security headers в действующий Caddyfile и выполнить:

```bash
caddy validate --config /etc/caddy/Caddyfile
systemctl reload caddy
```
