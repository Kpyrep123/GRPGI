# World Config: импорт и экспорт JSON

Начиная с GRPGI 1.0.132 каждый обычный раздел World Config можно выгружать и загружать отдельно: персонажи, системы, планеты, NPC, снаряжение, статьи, навыки, кампании, боевые сцены и остальные категории, представленные в боковом меню.

## Использование

1. Откройте `World Config` и выберите категорию. В версии 1.0.134 кнопки находятся первым блоком окна, над журналом ДМа, списком категорий и редактором.
2. Нажмите `ЭКСПОРТ JSON`, чтобы получить редактируемый файл выбранного раздела.
3. После редактирования нажмите `ИМПОРТ JSON` и выберите файл.
4. Проверьте количество новых, изменённых и отсутствующих записей.
5. Выберите режим:
   - `ОБЪЕДИНИТЬ` — добавить новые записи и заменить записи с совпадающим `id`, сохранив остальные;
   - `ЗАМЕНИТЬ РАЗДЕЛ` — сделать выбранный раздел точной копией файла.

Импорт записывает выбранный раздел в пользовательское хранилище мира. Комплектные JSON-файлы приложения остаются шаблонами и больше не требуют ручной замены.

## Формат

Экспорт использует канонический корневой ключ раздела и не создаёт дублирующий `*_LIST`:

```json
{
  "EQUIPMENT": {
    "laser_rifle": {
      "id": "laser_rifle",
      "name": "Лазерная винтовка",
      "type": "weapon",
      "damage": "2d6",
      "rapidFireShots": 3
    }
  }
}
```

Для разделов-массивов используется массив:

```json
{
  "SYSTEMS": [
    { "id": "sol", "name": "Солнечная система" }
  ]
}
```

Импорт также принимает старый `*_LIST`, чистый массив, карту `id -> сущность`, одну сущность с `id` или обёртку `entities`.

## Защита данных

- Перед применением всегда показывается предварительный итог.
- Файл другого раздела отклоняется.
- Повторяющиеся, пустые и опасные `id` отклоняются.
- Максимальный размер файла — 64 МБ; максимум — 50 000 сущностей в разделе.
- При полной замене персонажей профиль `gm` обязателен и должен сохранить роль `gm`.
- Локальная запись выполняется по одному выбранному разделу; затем запускается штатная облачная синхронизация.
- При включённой раздельной синхронизации профилей импорт персонажей обновляет соответствующие профильные записи и удаляет отсутствующие только в режиме полной замены.

Несохранённые изменения в открытой карточке не включаются в экспорт и не смешиваются с импортом — сначала сохраните карточку обычной кнопкой `SAVE`.
