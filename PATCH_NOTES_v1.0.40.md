# GRPGI 1.0.40

## Web / PocketBase

- добавлен сохранённый вход по явной опции пользователя;
- параметры подключения сохраняются без паролей;
- PocketBase token восстанавливается и обновляется через `auth-refresh`;
- выбранный профиль автоматически открывается после перезагрузки страницы;
- локальное хранение ограничено 30 днями;
- добавлена кнопка «Забыть устройство»;
- удаляется старое состояние браузера прежнего backend;
- web-deploy блокируется, если в `deploy/site` найдены остатки прежнего backend;
- добавлены cache-busters, build-info и security headers/CSP;
- обязательный consent-gate на странице загрузки удалён;
- политика конфиденциальности обновлена под сохранённый вход.

## Важно

`deploy/site/privacy.html` содержит незаполненное поле юридического имени и адреса оператора. Его нужно заполнить до публичного использования.
