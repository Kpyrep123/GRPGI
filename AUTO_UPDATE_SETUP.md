# Обязательные обновления GRPGI с собственного сайта

Desktop-клиент использует `electron-updater` и generic-канал:

```text
https://app.grpg-sync.ru/downloads/latest.yml
```

GitHub Releases, GitHub Actions и `GH_TOKEN` для выпуска больше не требуются.

## Публикация новой версии

1. Запустить проект из исходников: `npm start`.
2. Войти под ДМом.
3. Открыть профиль.
4. Нажать `СОБРАТЬ И ОПУБЛИКОВАТЬ ПК`.
5. Не закрывать приложение до сообщения об успешной публикации.

Операция автоматически:

1. сравнивает локальную и опубликованную версии; уже подготовленную новую версию не повышает повторно, а при следующем выпуске увеличивает patch в `package.json` и `package-lock.json`;
2. собирает Windows NSIS-установщик командой `npm run release:local`;
3. проверяет, что `latest.yml` относится к новой версии;
4. загружает версионный `.exe`, `.blockmap`, `GRPGI-Setup-latest.exe` и `release.json`;
5. проверяет SHA-256 загруженных файлов на сервере;
6. публикует `latest.yml` последним атомарным переименованием.

Если сборка или загрузка не завершилась, версия в исходниках возвращается к прежней, а незавершённый релиз не объявляется клиентам.

## Поведение приложения

- packaged-сборка проверяет `latest.yml` при каждом запуске;
- пока сервер не подтвердил актуальную версию, интерфейс заблокирован;
- новая версия скачивается автоматически;
- после загрузки требуется нажать `УСТАНОВИТЬ И ПЕРЕЗАПУСТИТЬ`;
- если сервер недоступен, доступ остаётся заблокированным, доступны повторная проверка и ручное скачивание с сайта;
- при запуске через `npm start` блокировка отключена, чтобы не мешать разработке.

## Первый переход с GitHub-канала

Уже установленная старая сборка содержит старый адрес GitHub и не может узнать новый адрес сайта. Поэтому один раз требуется вручную установить первую сборку с новым updater через:

```text
https://app.grpg-sync.ru/downloads/GRPGI-Setup-latest.exe
```

Все последующие обновления будут обнаруживаться на сайте автоматически.
