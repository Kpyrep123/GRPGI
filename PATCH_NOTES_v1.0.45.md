# GRPGI 1.0.45 — Web Galaxy Realtime

## Исправлено масштабирование галактики

- Фоновые слои галактики, звёзды, маршруты, системы и планеты используют одну камеру.
- Фон теперь масштабируется и перемещается вместе с метками.
- Масштабирование выполняется относительно позиции курсора.
- Камера карты сохраняется в `sessionStorage` и восстанавливается после повторного рендера/перезагрузки вкладки.

## Карта отделена от обновления данных

- Активная desktop-карта больше не уничтожается при обновлении snapshot или данных персонажей.
- Realtime-события меняют модель данных и инспектор карты без пересоздания canvas.
- Выбранная система и положение камеры сохраняются.

## Event-driven realtime

- Удалены циклические `setInterval`-опросы PocketBase.
- Удалены старые `snapshotPollMs` / `livePollMs` и неиспользуемый `pullLiveData`.
- Snapshot, игроки, чат и combat runtime применяются непосредственно из PocketBase realtime-событий.
- После фактического разрыва соединения выполняется переподключение и один полный resync.
- Один resync также выполняется при возврате вкладки после потери realtime или восстановлении сети.
- Полный resync также не сбрасывает камеру галактики.

## Автоматический технический вход PocketBase

- Экран технической авторизации `app_users` удалён из Web UI.
- Игрок видит только выбор персонажа и пароль персонажа.
- DEV+DM Web deploy берёт PocketBase URL, campaign ID и техническую пару `app_users` из локальной конфигурации Electron.
- Данные внедряются только во временную копию `deploy/site` перед SCP.
- Исходный `deploy/site/app/runtime-config.js` не содержит логина или пароля.
- Временная staging-папка удаляется после деплоя.

## Mobile

- Мобильная адаптация до 900 px остаётся облегчённой и не создаёт desktop canvas карты.
