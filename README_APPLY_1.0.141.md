# GRPGI 1.0.141 — внешний вид и характеристики предметов

Это **дополнение к полным исходникам 1.0.140**, а не отдельный установщик и не замена сервера. `pb_hooks`, база PocketBase, сохранения и механизм торговли не изменяются. Патч меняет 10 файлов клиента: четыре новые CSS/JS, пять существующих файлов интерфейса и `package.json`.

## Исправления

- Технологичная эра: кнопки глобальной карты, дорожки и фон веб-карты, карточки и клетки инвентаря и терминала оформлены тёмным металлом и янтарём. Цвета остальных эр не меняются.
- Архив и окно выбранного товара на ПК и в веб-версии показывают скорострельность, магазин, расход патронов, массу, габариты, броню, прочность, заряды и **каждый включённый модификатор**. Для модификаторов отображаются знак, ноль, условие и область действия; отключённые не показываются. Характеристики предметов не меняются при отображении.
- Убрано ограничение веб-вывода до трёх выстрелов; значение из данных, например шесть выстрелов, показывается без обрезки.

## Установка в Windows PowerShell

Путь `C:\app_backup` ниже обозначает папку **исходного проекта** с `package.json`, `renderer` и `deploy`, где версия `1.0.140`. Укажите свой путь, если проект расположен иначе. Не запускайте эти команды на сервере PocketBase или в папке установленной игры.

1. Распакуйте этот архив, например в `C:\GRPGI-patch-141`.
2. Проверьте совместимость, не записывая файлы:

   ```powershell
   node "C:\GRPGI-patch-141\APPLY_PATCH_1.0.141.cjs" "C:\app_backup" --check
   ```

   Ожидаемый результат: `Проверено: 10 клиентских файлов. Изменения не записаны.` Если проверка не прошла, остановитесь. Патч рассчитан на исходник 1.0.140 и не должен устанавливаться поверх 1.0.139.

3. Примените проверенный патч:

   ```powershell
   node "C:\GRPGI-patch-141\APPLY_PATCH_1.0.141.cjs" "C:\app_backup"
   ```

   Скрипт сохранит прежние файлы в `C:\app_backup\.backup-before-v141-...`, затем обновит клиент. Запуск второй раз блокируется проверкой версии.

4. Откройте обновлённый проект в DEV-профиле. Последовательно выполните встроенные действия публикации веб-версии и **«Собрать и опубликовать ПК»**. Для нового установщика нужно выполнить сборку, одного веб-деплоя недостаточно.
5. Проверьте заголовок окна приложения (версия `1.0.141`), архив предмета и терминал, а также после публикации `https://app.grpg-sync.ru/downloads/release.json` — там должна появиться версия `1.0.141`.

Серверные hooks дополнительно загружать и PocketBase перезапускать **не требуется**.

## Проверка и восстановление

При установке проводилась автоматическая проверка каждого фрагмента перед записью. Если исходник отличается, скрипт прекращает работу до изменений. На случай ошибки записи создана резервная копия затронутых прежних файлов; скрипт также пытается вернуть их автоматически.

Для ручного возврата скопируйте содержимое созданной папки `.backup-before-v141-...` обратно в корень исходников с заменой файлов и удалите четыре новых файла:

- `renderer/item-facts-v141.js`
- `renderer/technology-theme-v141.css`
- `deploy/site/app/item-facts-v141.js`
- `deploy/site/app/technology-theme-v141.css`

Работа логики проверена на доступном исходнике 1.0.139 и на контрольной копии, обозначенной 1.0.140. Архив подлинного релиза 1.0.140 не удалось получить из хранилища (HTTP 502), поэтому первым действием на вашем подлинном проекте обязателен `--check`; без успешной проверки не публикуйте обновление.
