# GRPGI 1.0.56 — Campaign Studio

Добавлен отдельный ДМ-модуль `Campaign Studio` рядом с World Config.

## Паутина кампании

- Для каждой игровой кампании хранится отдельная паутина.
- В паутину можно добавлять существующие сущности World Config без копирования их данных.
- Узлы-ссылки автоматически показывают актуальное имя сущности после её изменения в World Config.
- Поддерживаются отдельные свободные заметки ДМа.
- У каждого узла есть собственная заметка.
- Связи между узлами имеют произвольные подписи.
- Узлы перетаскиваются; поле поддерживает панорамирование и масштабирование.
- Есть команды «Показать всё» и «Центр».
- Из инспектора можно открыть исходную сущность непосредственно в World Config.

## Вехи сюжета

В карточку игровой кампании в World Config добавлен раздел `Вехи сюжета`.

У вехи есть:
- название;
- описание;
- состояние «достигнута».

Определения вех редактируются в листе кампании. Их состояние можно оперативно переключать и в Campaign Studio.

## Дерево сюжета

Дерево сюжета также хранится отдельно для каждой кампании.

Поддерживаются:
- сюжетные элементы;
- финалы / исходы;
- условия;
- случайные события;
- подписанные ветки между сюжетными элементами;
- статусы `запланировано / активно / завершено / сорвано`.

### Общие условия

Условие является отдельным объектом дерева и ссылается на одну или несколько вех кампании.

Режимы условия:
- должны быть достигнуты все выбранные вехи;
- достаточно достижения любой выбранной вехи.

Одно условие может быть назначено неограниченному количеству сюжетных элементов.

### Случайные события

Случайное событие имеет вес. Команда `БРОСИТЬ СОБЫТИЕ`:

1. исключает завершённые и сорванные события;
2. исключает события с невыполненными условиями;
3. выбирает одно из оставшихся событий пропорционально его весу.

## Хранение данных

Данные Campaign Studio входят в общий world snapshot как `campaignStudio` и синхронизируются существующим механизмом PocketBase.

Модуль доступен только профилю с ролью `gm`.
