# Patch 1.0.39

## Исправление установки зависимостей

- Все внутренние URL сборочной среды удалены из `package-lock.json`.
- Все npm-пакеты теперь загружаются с официального `https://registry.npmjs.org/`.
- Добавлен проектный `.npmrc`, фиксирующий официальный npm registry.
- Добавлены повторные попытки загрузки при временных сетевых сбоях.
- Версия приложения и `buildVersion` обновлены до 1.0.39.

## Чистая установка на Windows

```cmd
cd /d "C:\app копия"
rmdir /s /q node_modules 2>nul
npm cache verify
npm ci
npm start
```

## Загрузка Electron

- Установка сначала использует официальные релизы GitHub.
- При недоступности GitHub автоматически пробуется резервное зеркало `npmmirror`.
- Прокси автоматически учитывается при наличии `HTTP_PROXY` или `HTTPS_PROXY`.
- `INSTALL_AND_RUN.cmd` больше не удаляет уже скачанный бинарник Electron повторно.
