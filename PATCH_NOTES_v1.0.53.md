# GRPGI 1.0.53 — Startup regression fix

## Исправлено

- Восстановлен объект `ChatUI`, случайно удалённый в 1.0.52 вместе с активными механиками дешифратора/взлома.
- Восстановлен объект `Persistence`, попавший в тот же ошибочно удалённый диапазон кода.
- Мини-игры дешифратора и взлома остаются удалёнными; возвращены только инфраструктурные компоненты, которые к ним не относятся.
- Селектор игровой кампании снова создаётся при штатном `App.fillLoginSelect()` и показывает только доступные кампании без подписи эпохи.
- Добавлен явный обработчик ошибки `App.init()`: если будущая ошибка запуска повторится, приложение покажет её на экране входа вместо визуального зависания.

## Проверка

- 1.0.52: воспроизводится `ReferenceError: ChatUI is not defined` до завершения загрузки приложения.
- 1.0.53: `renderer/app.js` выполняется без исключения.
- `App.init()` на тестовом world-data завершается успешно.
- Селектор кампании создаётся и заполняется.
- Селектор персонажа создаётся и заполняется.
- npm install / npm ci не выполнялись.
