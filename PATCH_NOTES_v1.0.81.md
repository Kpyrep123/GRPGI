# GRPGI 1.0.81 — изоляция оформления статей

## Исправления

- CSS из HTML-кода статьи больше не изменяет заголовки, абзацы, списки, кнопки и другие элементы приложения.
- Каждая отображаемая статья получает уникальную область стилей. Селекторы `h1`, `p`, `footer`, `.lead` и другие автоматически ограничиваются этой областью.
- Вложенные правила внутри `@media`, `@supports`, `@container` и `@layer` также ограничиваются текущей статьёй.
- Встроенные атрибуты `style`, фоновые изображения `data:` и декоративные псевдоэлементы сохраняются.
- Внешние таблицы стилей через `<link rel="stylesheet">` и `@import` удаляются, поскольку они способны изменять весь документ.
- Исправление действует в Electron-приложении и веб-версии.

Существующие статьи редактировать не требуется.

## Установка

1. Наложить архив на корень проекта с заменой файлов.
2. Выполнить обычный `ДЕПЛОЙ WEB`.
3. Собрать установщик GRPGI 1.0.81.
4. Заменить файл `GRPGI-Setup-latest.exe` на сайте.

Изменения PocketBase, перезапуск PocketBase и reload Caddy не требуются.
