# Web Galaxy Map

Версия 1.0.44 переносит игроковую галактическую карту из Electron в браузерный desktop-интерфейс.

## Режимы

### Desktop web

При ширине окна больше 760 px домашний модуль показывает карту.

Управление:

- drag по свободной области — перемещение карты;
- колесо мыши — масштабирование относительно указателя;
- клик по системе — системный скан справа;
- двойной клик — вход внутрь системы;
- «МОЯ СИСТЕМА» — переход к системе текущей планеты персонажа;
- «ЦЕНТР» — сброс камеры;
- поиск — по markerLabel, имени или ID системы.

Внутри системы планеты показываются на орбитах. Выбор планеты открывает скан, а кнопка «Открыть карточку» переходит к существующему архивному представлению.

### Mobile web

При ширине до 760 px карта не создаётся. Используется существующий облегчённый навигатор по системам и планетам.

## Источник данных

Карта использует существующие поля `world.systems.SYSTEMS` и `world.planets.PLANETS` из PocketBase snapshot. Дополнительной серверной коллекции не требуется.

Поддерживаются поля системы:

- `id`;
- `name`;
- `markerLabel`;
- `markerStyle`;
- `color`;
- `pos.x`, `pos.y`;
- `planetIds`;
- `routes`;
- `visibility`.

Поддерживаются типы меток: `orbital`, `node`, `blackhole`, `ship`, `diamond`, `square`, `credits`.

## Вход

Отдельный setup-screen больше не используется. Сервер и кампания заданы приложением. PocketBase по-прежнему требует auth-токен `app_users`; на новом устройстве технические credentials вводятся в раскрывающемся блоке того же экрана «Вход за персонажа».
