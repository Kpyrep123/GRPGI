# GRPGI 1.0.82 — ссылки и скрытые статьи

## Ссылки на статьи

- Ссылки формата `<a href="article:article_id">Текст</a>` теперь обрабатываются во всей веб-версии, включая личные, общие и NPC-чаты.
- При переходе из веб-чата мастер-окно переписки закрывается, после чего открывается карточка статьи в архиве.
- Прямая ссылка предоставляет доступ к конкретной статье независимо от ограничений по персонажу, кампании и эпохе.
- Это исключение действует только для статьи, ID которой передан в ссылке. Остальной каталог продолжает соблюдать обычные правила доступа.
- Такое же правило прямого доступа действует в Electron-приложении.

## Статьи «только по поиску»

- В World Config → Статьи добавлен флаг «Доступна только по поиску».
- Отмеченная статья не показывается в каталоге, категориях, избранном и недавних материалах без поискового запроса.
- Статья появляется, если слова поискового запроса содержатся в её названии.
- Поиск не отменяет обычные ограничения доступа. Обойти их можно только прямой ссылкой `article:ID`.

## Установка

1. Наложить архив на корень проекта с заменой файлов.
2. Выполнить обычный `ДЕПЛОЙ WEB`.
3. Собрать установщик GRPGI 1.0.82.
4. Заменить файл `GRPGI-Setup-latest.exe` на сайте.

Изменения PocketBase, перезапуск PocketBase и reload Caddy не требуются.
