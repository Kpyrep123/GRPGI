Galactic RPG Interface

Клиент кампании

Здесь размещаются три способа входа: ПК-клиент, APK для телефона и веб-версия, которая открывается прямо в браузере. Веб-версия не хранит данные локально: всё подгружается из PocketBase и записывается обратно в облако.

Сервер синхронизации: https://sync.grpg-sync.ru
Windows / ПК

Полная версия

Режим ДМа, World Config, редакторы, боевые сцены, архив, чат, профиль, обновления и синхронизация через PocketBase.

Скачать ПК-версию

После сборки переименуй установщик в GRPGI-Setup-latest.exe и положи в папку downloads.

Web / браузер

Веб-версия

Тот же player-only клиент, адаптированный под телефон и браузер. Не сохраняет конфигурацию, кеш и профиль локально.

Открыть веб-версию

Все данные читаются из https://sync.grpg-sync.ru и записываются обратно в PocketBase.

Android / телефон

APK-версия

Устанавливаемый мобильный клиент без режима ДМа. Вместо галактической карты используется лёгкая навигация.

Скачать APK

После сборки APK переименуй его в GRPGI-Mobile-latest.apk и положи в папку downloads.

Параметры подключения

Backend
PocketBase
Server URL
https://sync.grpg-sync.ru

main
