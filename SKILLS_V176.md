# Навыки: каталог и зависимости (v176)

> Основной экран заменён радиальным деревом v177. Актуальная инструкция: `SKILLS_V177.md`. Ниже — описание резервного представления и общих тегов/HTML.

В профиле игрока основной вид — каталог. Слева находятся поиск, фильтры состояния, прямых требований к характеристикам и тегов. Несколько выбранных тегов работают как «любой из выбранных». Сортировка: сначала доступные, по названию или по стоимости. Изученные навыки остаются в каталоге и доступны отдельным фильтром. Изображения, стоимость и активный/пассивный/реакционный тип сохраняются.

«Общие» в фильтре означает отсутствие прямых требований к характеристикам. Такой навык может быть самостоятельным или требовать другие навыки. Теги сами по себе не являются требованиями. Существующая категория и требования не меняются автоматически, названия тегов не генерируются из описания.

После выбора справа открывается описание с условиями, стоимостью и действием изучения. Режим «Связи» показывает предшественников, продолжения и дополнительные предшественники этих продолжений. Он намеренно не применяет фильтры каталога, чтобы условия не исчезали из цепочки. Независимый навык отображается одним узлом. Искусственных корней характеристик нет. Все видимые требования показываются стрелками, в том числе при нескольких предшественниках. Скрытые или отсутствующие записи обозначены без раскрытия их названий.

Размещение связей вычисляется автоматически по уровням зависимостей со стабильным порядком по ID. Оно не меняет `requiredSkillIds`, характеристики, ID или старые `treePos`. Циклы не исправляются автоматически: интерфейс сообщает об ошибке для исправления ДМом в World Config. Доступны перетаскивание свободного поля мышью/средней кнопкой, кнопки масштаба, Ctrl + колесо, вся цепочка, центрирование выбранного и сброс вида. Фильтры, выбор, режим, масштаб и прокрутка сохраняются в памяти для текущего игрока при перерисовках. После перезапуска страницы начинается новая сессия просмотра.

## World Config

В карточке каждого навыка есть «Теги навыка»: список с поиском, видимыми отметками и несколькими выбранными значениями. Можно вписать новый тег; существующее название переиспользуется без учёта регистра. Новое название остаётся в черновике карточки до сохранения. Варианты берутся из сохранённых навыков; это отдельное пространство от торговых тегов. Если тег больше не используется ни одним навыком, он не показывается в вариантах других карточек.

Теги хранятся строковым массивом `tags` внутри записи навыка. Они проходят обычное сохранение, синхронизацию, экспорт/импорт `skills.json` и бэкап кампании. Старые навыки без `tags` имеют пустой список. Отдельная миграция и отдельный файл тегов навыков не требуются. Поля категории, Lua, условий и владения сохраняются прежними механизмами.

У описания есть предпросмотр. Обычный текст поддерживает абзацы и переносы. Поддерживается очищенная HTML-разметка: абзацы, заголовки h2–h4, списки, выделение, цитаты, код, таблицы и ссылки http/https/mailto. Скрипты, обработчики событий, встроенные стили, формы, фреймы, изображения и опасные протоколы не выполняются и не попадают в описание. Исходный текст описания при показе не изменяется.

## Обновление

Обновить desktop source/bundle и перезапустить клиент. Для игроков в браузере выполнить обычный Deploy Web с этой ревизии. Новые общие JS/CSS находятся и в `renderer`, и в `deploy/site/app`; копии должны совпадать. Не нужно копировать desktop `app.js` поверх web `app.js` — это разные адаптеры.

Серверные службы, схема базы и правила покупки не менялись. Версия установщика остаётся 1.0.155. Покупка и повышение характеристик используют существующие подтверждения, проверку условий и сохранение профиля; клиентские фильтры не разрешают обход условий. Слава остаётся выдаваемой ДМом.
