# GRPGI 1.0.48 — Web deploy permissions fix

- Исправлен HTTP 403 после автодеплоя Web.
- Причина: `scp` выполняется от root; при `umask 077` новый сайт мог получить права 0700/0600, из-за чего пользователь Caddy не мог читать `/var/www/grpg-app`.
- Перед атомарным переключением каталога все каталоги Web теперь нормализуются до 0755, файлы до 0644.
- После переключения выполняется повторная нормализация как защитная проверка.
- HTTP health-check остаётся диагностическим и не инициирует rollback.
- npm install/npm ci не выполнялись.
